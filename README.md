# CI/CD Pipeline with Jenkins

A practical CI/CD pipeline demonstrating automated build, testing, and deployment using Jenkins and Git.

## Project Overview

This project demonstrates a basic Continuous Integration and Continuous Delivery (CI/CD) workflow.

The pipeline is configured using a Jenkinsfile and includes automated testing as part of the deployment workflow.

## Technologies Used

- Jenkins
- Git
- GitHub
- HTML
- Jenkins Pipeline
- Automated Testing
